# 聚会页摇骰子：原模型、原动作和原音效

入口位于聚会小游戏列表首位，路由 `/dice/pages/play/index`。保留1–6颗选择、按钮/摇动手机开始、开盅、盖盅、总和与各点数统计，复用既有会员免广告策略。摇一摇、开盅、盖盅与切换骰子数量按钮接入共用插屏规则：本次打开小程序第3次有效操作起30%概率，共用25次有效操作兜底，广告位随机且不连续重复。重复点击当前骰子数量不计为有效切换；手机摇动和画布手势不触发广告。广告关闭或加载失败后继续原操作，切后台取消待执行操作，卸载释放广告实例。

## 本轮修正

上一版是骰盅PNG、CSS摇动/淡出与六张点数图，并用宿主短提示音代替碰撞声，未达到用户要求的原App真实效果。本轮运行画面已改为实时WebGL1模型：

- 原黑色盅体与原底盘均为独立三维网格，底盘不再用CSS椭圆代替。
- 直接读取原 `rock_2`、`open_2`、`open_3` 动画，复现盅体/底盘摇动、抬盅横移和逆向盖回。开合过程不以透明度消失代替。
- 骰子使用原 `dice_Baked` 网格，运行时旋转、弹动、碰撞；不再用预渲染PNG表现最终结果。落定后每颗骰子的朝上面与点数一致，盖回再开不会重新抽点数。
- 原始 `collDiceBox`、`collDice`、`collTable` 三段音效已从外置资源流成功解码。此前解码失败是没有正确读取独立的 `sharedassets0.resource`，并非资源缺失。
- 摇动音效在实际摇动动画开始时播放；落定与盖回分别播放原短碰撞声。遵循聚会页的声音开关；启用声音时骰子专属声道设为 `obeyMuteSwitch=false`，避免iOS静音拨片使用户已开启的游戏声音完全无声，不改变其他游戏的设置。
- 增加上滑开盅、下滑盖盅，并防止同一手势后的tap重复触发。
- 加载失败显示简短提示和重试按钮，不暴露GL技术报错，也不静默退回静态图片。

## 实现边界

本轮复用原模型、原动画采样和原音频，在微信原生Canvas内用轻量WebGL1播放器呈现。没有加载原APK的Unity/账号/广告/支付SDK。动画原曲线采样为60fps，运行时按实际时钟插值；镜头构图和灯光为小程序画布适配。

骰子碰撞使用本地轻量运动模拟，并在落定后按本轮点数定向，不等同于完整迁移Unity PhysX或原App所有皮肤、材质和功能。因此可以确认资源和动作数据的来源，不能把本地截图描述为与原App逐像素、逐物理帧一致。

## 修改范围与重建

- `miniprogram/dice/renderer.js`：原模型WebGL1渲染、源动画播放器、底盘与接触阴影、像素比、取消与GPU资源释放。
- `motion.js`：源动作插值、骰子朝上面、盅内运动与碰撞。
- `audio.js`：原三段音效、应用声音偏好与生命周期管理。
- `pages/play/`：画布接入、开合动作锁、上/下滑手势、加载重试、后台/尺寸变化恢复。
- `scene.js`、`assets/scene.bin`、`cup.wav/dice.wav/table.wav`：由脚本生成，不手工修改。

```bash
python3 -m venv /tmp/wx-dice-python
/tmp/wx-dice-python/bin/pip install -r tools/requirements-dice-assets.txt
/tmp/wx-dice-python/bin/python tools/import-dice-scene.py --source '<data.unity3d路径>'
node --test tests/*.test.js
node tests/dice-render.cjs
```

构建工具使用 [UnityPy](https://github.com/K0lb3/UnityPy) 读取Unity资源、使用UnityPy依赖的fmod-toolkit解码音频。模型打包为16字节顶点和Uint16索引，二进制566,528字节，运行时没有Babylon或新增第三方引擎依赖。旧 `import-dice-assets.py` 与 `render-dice-assets.cjs` 仅用于保留的素材预览/入口图标，不负责当前实时场景。
