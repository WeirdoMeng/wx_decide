# 头顶猜词、十秒挑战、你比我猜

## 页面与入口

聚会小游戏顺序：摇骰子、头顶猜词、十秒挑战、你比我猜，后面保留原六个小游戏。原场景生成数据不改动，新增入口由聚会页组合。

新增独立 `partyplay` 分包，复用原主背景、透明导航、圆角卡片和蓝紫按钮，不依赖云端、登录或会员。路由：

- `/partyplay/pages/words/index?mode=heads`：头顶猜词，固定横屏。
- `/partyplay/pages/words/index?mode=charades`：你比我猜，固定横屏。
- `/partyplay/pages/timing/index`：十秒挑战，沿用竖屏。

横屏保留刘海侧留白，设置、答题及结果均为一屏布局，结果明细每页4条；导航返回由页面处理，进行中提示退出并暂停/作废计时。

## 功能

### 头顶猜词

选择分类和60/90/120秒，3秒准备后直接按钮答题，不需要传感器或答题方式选择。屏幕中央仅展示放大的词语；底部“跳过 / 答对了”各占一半宽度，右上角独立蓝色暂停按钮。

答对加1，跳过不扣分，不提供撤销。重复快速点击有350毫秒保护。暂停会清空词语并冻结倒计时；切后台同样暂停，回来后主动继续，保留同一题和剩余时间。

### 你比我猜

快速玩或2–4队比赛，每队1–3轮，通过“设置队名”选择队伍后弹窗修改，最多8字。表演者看词做动作，不能说出题目中的字，由按钮判定答对/跳过。

同场共用不重复题序；各队轮流，传手机阶段不计时，下一队主动准备才开始。每轮展示词语明细；整场展示各轮成绩与总分排名，同分并列。

### 十秒挑战

目标5/10/15秒，默认10秒；“自定义”弹窗可输入1–300秒整数，取消不改设置，非法输入提示重填。单人练习或2–8人对决，每人1次或3次。1–2秒目标开始后立即隐藏；其他目标显示目标时长的20%，最多1秒，此后不提供节拍动画、音效或震动。

按停时读取真实经过时长，优先使用 `wx.getPerformance().now()`，不以定时器次数计分；用分:秒.毫秒数字时钟展示，结算、误差与最佳纪录保留三位小数，比较绝对误差，多次按平均绝对误差排名，显示精度相同则并列。按目标独立保存本机最佳误差。

计时期间切后台、打开说明或超过本次容错时限（60秒与目标时长+10秒中的较大者）均作废当前尝试，不写成绩，重试保持当前玩家。

## 题库

`partyplay/words.js` 按玩法提供两套独立词库，各6类、每类50条，每套300条，共600条且无重复文本。

- 头顶猜词偏口头描述的名词：日常物品、动物世界、美食饮品、影视角色、职业身份、地名景点。例如企鹅、咖啡师、鼓浪屿。
- 你比我猜偏无需道具即可表演的动作和场景：日常动作、运动竞技、动物模仿、职业表演、生活场景、动作成语。例如企鹅走路、咖啡师拉花、赶飞机。

分类菜单、混合题池、本机已见记录均按玩法隔离。混合/分类模式优先未见词，题库用尽后可重新循环；同场最多使用一遍题库，不重复抽词。

## 广告与声音

只在完整单局或分组整场结束后点击“再来一局/再挑战一次”时接入现有共用插屏：本次打开第3次有效操作起30%，25次有效操作兜底，随机广告位不连续重复，会员免广告。答题、计时和比赛中途换队不触发。

声音、震动遵循聚会设置。短声道在下一音效及离开页面时直接销毁，不对未播放/空闲声道调用 `stop()`。退后台或卸载清除计时器和广告待执行操作。
