## 内容原则

- 面向朋友、同学、同事的日常聚会，以轻松、自我表达、幽默和现场互动为主，恋爱只保留少量。
- 真心话覆盖糗事、童年校园、生活经历、习惯喜好、友情、自我认识与脑洞选择；不通过改写近义词或替换角色凑数。
- 大冒险覆盖搞笑表演、语言创作、合作互动、声音与小才艺；尽量在十到三十秒内用现场条件完成。互动邀请愿意参与的人，不要求对外发消息、公开隐私、身体接触或喝酒。
- 逐题复查题意，避免同一任务只换题材重复出现；程序额外检查去除标点、空白及全半角差异后的重复文本。文本相似度检查用于辅助复查，不代替题意审阅。

## 修改及生成

原始场景归档 `docs/source-data/13011.json` 不用于手工维护扩展题。扩展内容只修改 `docs/source-data/questions-extra.json` 的 `truths` 和 `dares` 数组，然后执行：

```bash
python3 tools/import-scenes.py --questions-only
node --test tests/*.test.js
```

生成结果为 `miniprogram/data/questions.js`，不要单独编辑这个生成文件。完整场景导入也会合并扩展源，不会把题库恢复成各 6 条。导入遇到空题、重复文本或任一类不足 100 条会报错。

抽题继续使用现有 QuestionDeck：每个模式独立记录已抽题目，同一轮抽完前不重复；全部抽完后开启下一轮，避免与上一轮最后一题相同。已读进度按题目原文保存，因此原题进度可继续使用。新题会进入本轮剩余题目。
