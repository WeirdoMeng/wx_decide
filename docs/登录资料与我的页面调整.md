# 登录资料与“我的”页面调整

## 2026-11-02 头像昵称收集整改

以微信官方通知截图为本次整改依据：删除在进入小程序等非必要场景要求提供头像昵称的流程。

- 默认入口改为首页，游客直接使用转盘、聚会及所有玩法。启动、分享、扫码直达不再跳转登录页；“我的”页也可直接浏览。
- 首次进入不发起账户登录、头像选择或昵称填写。仅对之前主动登录且未退出的账户恢复登录及会员权益，不弹出资料表单。
- 用户主动点击登录、购买或恢复会员时展示纯账户登录页，不展示头像昵称组件；支持“暂不登录，直接使用”和返回。
- 登录成功后不检查 profileComplete。资料为空的账户同样可以购买、恢复会员，权益仍由服务端确认。
- 头像昵称仅在“我的 → 编辑头像和昵称（选填）”主动进入后填写，用于个人展示；可以直接返回，不影响任何玩法或权益。
- 游客显示默认头像与“游客”，已登录未完善资料时显示默认头像与“微信用户”。会员徽章仍由服务端免广告权益决定。
- 退出登录后留在“我的”的游客状态，不再强制回到登录页。
- 保留原账户归属、会员/退款确认、广告抑制、资料版本合并和云端安全校验；不删除用户已有资料。

## 本次验证

153 项 Node 测试通过，包括游客启动、扫码/分享路由不劫持、游客我的页、纯登录、未完善资料账户放行、用户主动编辑资料、原会员/支付/广告与玩法回归。微信模板编译结果见本次交付说明。以上为本地验证，需在手机上清除登录状态后验收，不能代替微信平台复审。

## 提审前手机验收

1. 新安装/清除数据后扫码进入首页，不出现登录或头像昵称表单；直接转盘及进入各个小游戏。
2. 测试分享/扫码直达游戏，以及切换三个 Tab，均不要求资料。
3. 在“我的”主动登录，不填写资料即可完成登录；购买/恢复权益仍可用。
4. 仅主动点击选填资料入口出现头像选择及昵称输入，返回后仍可使用所有功能。
5. 检查老会员权益恢复、退出登录后的游客状态；确认付款必须经服务端确认，不能凭客户端成功提示发放权益。

## 可填写的整改说明

已移除进入小程序、浏览页面、使用玩法以及登录/支付流程中的强制头像昵称收集。用户可免登录直接使用所有玩法，登录仅用于绑定和恢复会员权益，无需提供头像昵称。头像昵称改为“我的”页面中由用户主动进入的选填资料编辑功能，不填写或返回均不影响使用及购买权益。请审核更新后的版本。

## 更新方式

本次只修改小程序前端，无云函数接口或数据库结构变更。请在微信开发者工具使用首页普通编译，手机预览验收后上传新版，并按后台整改入口提交复审/重新提审；线上旧版本不会因本地修改自动更新。

## 资料持久化

- 新增当前账户的 updateProfile 云函数 action，不接收客户端指定的账户或会员身份。
- 头像经客户端文件读取传入云函数，由服务端校验 PNG/JPEG、体积不超过512KiB，上传到云存储。
- 云数据库原用户记录增加 nickname、avatarFileId、profileVersion；事务仅更新资料字段，保留最新会员、退款和订单字段。
- 原/沙盒用户集合继续隔离，头像路径也包含支付环境与当前账户目录。无需新建集合或索引。
- 服务端获取头像临时地址，不要求放宽客户端云存储读写权限；图片获取失败不阻断会员查单。
- 更新头像后清理旧文件；资料事务失败时清理本次新文件。
- 前端分别比较资料版本和会员权益版本，避免迟到的资料回复回退会员或退款状态。
