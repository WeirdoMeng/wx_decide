### 聚会入口 13010

保留完整物料对象，尤其是：

- 身份和排序：`id`、`materialId`、`sort`、`weigh`。
- 名称和介绍：`name`、`materialName`、`content`、`description`。
- 图片和媒体：`coverImage`、`materialGif`、`materialCoverImage`、`materialUrl`、`image`。
- 路由和关联规则：`routePath`、`routeParamId`、`functionId`、`is_free`。

Flutter 当前封面读取顺序为 `coverImage → materialGif → materialCoverImage → materialUrl → image`。原始字段都要保留，不能只保存页面上显示的图片。

当前源码支持以下八个后台 route key。实际响应是否包含全部入口，以获取结果为准；不要手工补造缺失项。

后台路由可能是 `0?route=truthDare`、带 `routePath` 的包装路由或普通路径。请保留完整字符串，包括查询参数和编码，迁移时统一转换成小程序路由。

### 真心话大冒险 13011

请导出完整分类树，递归保留所有 `children`，重点字段是 `name`、`description`、`children`。

现有解析规则：

1. 通过分类名“真心话”和“大冒险”确定题目归属。
2. 递归读取这些分类的下级分类。
3. 使用叶子分类的 `description` 作为题目内容，去除空内容和重复题目。

因此不要只导出分类名称、顶层列表或 material 名称，也不要提前改成猜测的题目格式。收到原始树后会提取为本地题库，并保留现有整轮不重复、换轮避免连续同题和进度保存行为。

### 备案信息 1087

保留完整列表，尤其是 `routeParamId`、`routePath`、`materialUrl` 等原始字段。

当前宿主实际从 `routeParamId` 的查询参数中读取 `icpCompany` 和 `icpRecord`。请保留原始编码；不要根据 `content` 或图片名称猜测主体和备案号。小程序最终展示的备案信息还需与小程序实际主体对应。

## 不能用静态场景替代的业务数据

以下内容不是一次导出场景 JSON 就能完成的：

- 登录 Token、用户身份、会员到期时间和剩余次数。
- 功能鉴权和次数消费：包括 `/open/common/auth` 的实时结果。
- 会员套餐：当前来自 `/open/common/member/goodsList`，不属于场景接口。
- 商品详情、订阅规则、订单创建、支付签名和订单状态。
- 启动开关：当前有 `/open/common/config/list` 等独立配置接口，不属于场景物料。
- 用户协议和隐私政策的完整正文：不能从聚会或备案场景推导，保留相关页面时需要可供小程序展示的正式内容。

场景 JSON 适合内置题库、入口和展示内容；真实会员、价格、鉴权及订单结果仍需按最终业务方案处理。不要将某个用户的一次成功响应当成所有用户的固定权限。

## 台球源码情况

提供的目录是 Vite、TypeScript、Babylon.js 的斯诺克网页项目，包含物理、斯诺克规则、AI、模型和音频资源。可继续基于该源码改造，不需要另行提供场景题库。

当前代码通过 `window.flutter_inappwebview.callHandler("billiardsEvent", ...)` 向 App 上报，通过 `window.billiardsHost.pause/resume/restart` 接收宿主控制。迁移需要替换宿主桥接。

该目录的规则状态机是 `SnookerMatch`，当前入口没有发现黑八实现或按模式切换黑八的处理。如果需要同时保留“3D 黑八”和“3D 斯诺克”，还需要补齐与 App 部署版本对应的黑八或完整游戏源码。

## 返回文件的组织方式

先交付以下三个 JSON 和获取条件即可开始核心内容迁移，媒体文件可随后补齐：

```text
小决定迁移数据/
  获取说明.txt
  scene_13010.json
  scene_13011.json
  scene_1087.json
  media/
```

`获取说明.txt` 注明品牌、接口环境、获取时间，以及是否使用分页或登录身份。不要包含 Token 或用户个人信息。可选场景按前述文件名追加到同一目录。

场景里的图片、GIF、音频和视频如果要真正内置，请同时导出原文件及 URL 与文件名的对应关系；如果暂时只有 JSON，保留完整媒体 URL 即可，后续再判断下载、压缩和资源存放方式。带临时签名的链接需说明有效期。
